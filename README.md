# همة للموارد البشرية

نظام متكامل لإدارة الموارد البشرية والشركات، مبني باستخدام Laravel، ويدعم تعدد الشركات والمستخدمين والصلاحيات، بالإضافة إلى تطبيق Flutter للخدمة الذاتية للموظفين.

## نبذة عن النظام

يوفر نظام **همة للموارد البشرية** منصة مركزية تساعد الشركات على إدارة الموظفين والحضور والإجازات والرواتب والسلف، مع توفير خدمات ذاتية للموظف من خلال الويب وتطبيق الجوال.

## التثبيت المحلي

استنسخ المشروع:

```bash
git clone https://github.com/omerkhom-droid/hr.git
cd hr
```

ثبت مكتبات PHP:

```bash
composer install
```

أنشئ ملف البيئة:

```bash
copy .env.example .env
```

على Linux:

```bash
cp .env.example .env
```

أنشئ مفتاح التطبيق:

```bash
php artisan key:generate
```

أدخل إعدادات قاعدة البيانات في ملف `.env`:

```env
APP_NAME="همة للموارد البشرية"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://127.0.0.1:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=hr_saas
DB_USERNAME=root
DB_PASSWORD=
```

شغّل migrations وseeders:

```bash
php artisan migrate --seed
```

أنشئ رابط التخزين:

```bash
php artisan storage:link
```

ثبت ملفات الواجهة:

```bash
npm install
npm run build
```

شغّل المشروع:

```bash
php artisan serve
```

ثم افتح:

```text
http://127.0.0.1:8000
```

## إعداد بيئة الإنتاج

اضبط القيم التالية في ملف `.env` الموجود على الخادم:

```env
APP_NAME="همة للموارد البشرية"
APP_ENV=production
APP_DEBUG=false
APP_URL=https://your-domain.com

LOG_CHANNEL=stack
LOG_LEVEL=error

SESSION_DRIVER=database
CACHE_STORE=database
QUEUE_CONNECTION=database
```

أدخل أيضًا بيانات قاعدة البيانات والبريد الإلكتروني الخاصة بالخادم.

نفّذ أوامر الإنتاج:

```bash
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan storage:link
php artisan optimize:clear
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

إذا كانت الواجهة تستخدم Vite:

```bash
npm install
npm run build
```

يجب أن يشير Document Root للدومين إلى مجلد:

```text
/public
```

ولا يجب توجيه الدومين إلى جذر مشروع Laravel مباشرة.

## إعداد المهام المجدولة

أضف Cron Job لتشغيل Laravel Scheduler كل دقيقة:

```bash
* * * * * cd /path/to/project && php artisan schedule:run >> /dev/null 2>&1
```

قد تستخدم المهام المجدولة لمعالجة:

- إغلاق الحضور تلقائيًا.
- احتساب الاستحقاقات.
- معالجة الأقساط.
- تحديث حالات الاشتراك.
- إرسال التنبيهات الدورية.

## إعداد Queue Worker

لتشغيل المهام والإشعارات في الخلفية:

```bash
php artisan queue:work --tries=3 --timeout=120
```

في بيئة الإنتاج يفضل تشغيل Queue Worker باستخدام Supervisor أو مدير عمليات مشابه.
